# Zen Vision GNOME indicator

`extension/` preserves the installed GNOME detection-box indicator for package
migration. The Florence/model process and model data remain in the user's
external workspace. The extension retains its source shell-version declaration;
validate it against the selected shell.

ZenPkgs consumes this package from its GitHub repository. Releases are
preferred; until a suitable release exists, ZenPkgs pins the latest commit.
Implementation and assets stay here, outside the package catalog.
